# Mission

## Goal

Build a proof-of-concept (POC) web application for a repair/maintenance contracting business. The app lets clients request fixes, keeps all clients and orders in one system, tracks each order through its lifecycle, records cost data for quotes and
invoices, and generates printable documents.

## Principles

- This is a POC, not production.
- Favor the simplest thing that works.
- Clarity over cleverness.
- A clickable demo over completeness.
- Do not add features beyond scope.

## Out of scope

These are intentionally not part of the POC:

- Rate engine
- Approval workflow
- Itemized materials
- Notifications
- Calendar
- Aggregate reporting
- Cloud storage
- Password reset
- Multi-language
